# Public feature matrix

| Public statement | Evidence class | Public wording | Boundary |
|---|---|---|---|
| Six primary product areas | Source + reachability | Routes to Home, Wellness, Fuel, Pilot, Data, and Profile | Do not imply equal completeness across areas |
| Workout planning | Source + reachability | Home connects to a structured session builder | Do not publish source or internal route details |
| Active-workout experience | Source + reachability | The private product includes a live-session workflow | Do not claim production runtime quality |
| Workout reports | Source + reachability | Generates versioned CSV and JSON workout reports | Always state `REPORT_ONLY` and non-restorable |
| Storage recovery states | Source | Models visible degraded-storage and recovery states | Do not call this a complete backup/restore system |
| SwiftUI and SwiftData | Source | Built as a private SwiftUI/SwiftData iOS product | Do not disclose proprietary architecture |

## Publication rule

If a future source review cannot re-establish a statement, remove or soften it.
Roadmap intent, filenames, or an old screenshot are not sufficient evidence.
